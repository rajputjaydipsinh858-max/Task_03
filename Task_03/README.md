# HTML and CSS Selector Project

## About the Project
This project demonstrates different HTML elements and CSS selectors, including Element, Class, ID, and Pseudo-class selectors.

## Project Structure
- `index.html` - Contains the structure of the webpage.
- `style.css` - Contains the CSS styling rules.
- `README.md` - Provides project documentation.

## Technologies Used
- HTML5
- CSS3

## CSS Selectors Used
- Element Selector
- Class Selector
- ID Selector
- Descendant Selector
- Pseudo-class Selector (`nth-child`)

## Key Features
- Different HTML headings and paragraphs.
- Ordered and unordered lists.
- Hyperlinks to external websites.
- Text and background color styling.
- CSS styling without excessive inline CSS.

## How to Run
1. Open the project folder in VS Code.
2. Open `index.html` in a browser.
3. View the webpage and its CSS styling.
